# Portfolio description

**Vision-Based Pan–Tilt Tracking**

A camera-based face-tracking prototype connecting Python/OpenCV to an Arduino Uno and two MG996R servos.

- Detected faces in webcam frames and selected the largest face in the V3 implementation.
- Mapped face position to bounded pan/tilt angle commands with smoothing.
- Sent angle setpoints over USB serial to an Arduino-controlled two-axis mechanism.
- Explored dead zones, proportional corrections and motion smoothing across three software versions.

Tags: Python, OpenCV, Arduino Uno, MG996R, serial communication, servo control.
