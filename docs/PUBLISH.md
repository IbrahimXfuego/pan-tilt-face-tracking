# GitHub publishing

Repository name: `pan-tilt-face-tracking`.

Upload the extracted project contents to the public repository, keeping README.md at the root. Preserve the Arduino sketch folder name `turret` and the `.ino` filename `turret.ino` so Arduino IDE opens it correctly.

Do not upload virtual environments, caches, generated executables or private configuration. Add build photos and demo links under `docs/media/` when available. Choose a project license according to your preferred reuse terms.

Add the repository URL only to the portfolio's completed **Vision-Based Pan–Tilt Tracking** project. The separate in-progress estimation project remains unchanged.
